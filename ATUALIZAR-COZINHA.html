PAES CABO · ESPAÇO CAFÉ

Cozinha mais simples.

Uma atualização para quem já instalou o Espaço Café.

Como vai funcionar

Após o pagamento ser confirmado no caixa, o pedido chega à cozinha. Quando estiver pronto, a equipe toca apenas em Pronto. Ele aparece como pronto para retirada. Na hora da entrega, o caixa ou a administração abre Pedidos → Abrir → Confirmar entrega, para permitir o fechamento correto do atendimento.

A cozinha continua recebendo somente pedidos com pagamento confirmado. Os antigos pedidos que já estavam em preparo continuam visíveis.

1. Atualize a pasta do projeto

Faça a atualização fora do horário de atendimento e feche as abas antigas da equipe até terminar.

  1. Extraia o ZIP.
  2. Abra no VS Code a pasta que você já usa para o Espaço Café: nela está o arquivo package.json.
  3. Copie o conteúdo da pasta espaco-cafe do ZIP para a pasta existente e aceite substituir os arquivos de mesmo nome. Inclua as pastas src, public, supabase e tests.
  4. Preserve sua pasta .git e o arquivo .env.local já configurados. O ZIP não traz senhas e não contém o arquivo .env.local.

Se você fez outras mudanças no código depois da versão que recebeu, guarde uma cópia da pasta antes de substituir os arquivos.

2. Atualize o Supabase existente

  1. Entre no mesmo projeto Supabase do Espaço Café.
  2. Abra SQL Editor → New query.
  3. No VS Code, abra o arquivo supabase/04-cozinha-pronto.sql desta atualização.
  4. Copie todo o conteúdo do arquivo, cole no SQL Editor e clique em Run.
  5. Confirme que aparece uma mensagem de sucesso. Essa atualização troca as funções da cozinha e do painel de retirada; ela não apaga os pedidos, o estoque ou as contas existentes.

Para uma instalação nova, use o guia COMECE-AQUI.html: o arquivo inicial 01-estrutura.sql já inclui o novo comportamento, sem precisar executar o 04 separadamente.

3. Publique o código atualizado

Se o projeto estiver conectado ao GitHub, no terminal do VS Code verifique git status e, se as alterações estiverem corretas, execute:

git add .
git commit -m "Simplifica o painel da cozinha"
git push

Na Vercel, abra o projeto do Espaço Café → Deployments e aguarde aparecer Ready. Se não usar GitHub, publique pelo mesmo método usado na instalação existente.

Quando o código e o SQL estiverem atualizados, recarregue a página nos aparelhos do caixa e da cozinha.

4. Faça um teste antes do culto

  1. Abra um atendimento e registre um pedido de teste.
  2. Confirme o pagamento no caixa; só então ele aparece na cozinha.
  3. Na cozinha, toque em Pronto e confirme que o painel de retirada mostra a senha.
  4. No caixa, abra Pedidos → Abrir → Confirmar entrega. Confirme que o pedido sai da lista de prontos e que é possível fechar o atendimento após resolver todos os pedidos.

O sistema registra os recebimentos; a confirmação de Pix e cartão continua sendo feita no banco ou na maquininha.

Se aparecer uma mensagem de erro, não crie outro projeto nem apague os registros: envie um print da mensagem para receber ajuda.
