Já usa o Espaço Café?

Para atualizar a cozinha do sistema existente, abra primeiro ATUALIZAR-COZINHA.html. Não é preciso criar outro projeto do Supabase. As instruções abaixo são para instalação nova.

01.Abra e experimente.

Extraia o ZIP e abra a pasta espaco-cafe no VS Code. Instale o Node.js 22.12 ou uma versão mais recente da série 22. Abra o terminal e execute uma linha por vez:

npm install
npm run dev

Abra o endereço Local que aparecer no terminal. Sem as variáveis do Supabase, você verá uma demonstração local identificada. Em /login você pode experimentar os três perfis.

Os pedidos desse exemplo são fictícios. Na versão publicada, sem configuração o sistema fica bloqueado para vendas.

02.Prepare o Supabase.

  1. Crie um projeto novo para o Espaço Café.
  2. Abra SQL Editor e execute o conteúdo completo de supabase/01-estrutura.sql.
  3. Em Authentication → Users, crie e confirme o administrador.
  4. O e-mail inicial é dknsdaniel@gmail.com. Se quiser outro, altere o e-mail dentro de supabase/02-administrador.sql.
  5. Execute 02-administrador.sql depois de criar o usuário.
  6. Opcional: execute 03-cardapio-exemplo.sql para criar exemplos ocultos que você poderá editar.

03.Faça a conexão.

Crie um novo arquivo chamado exatamente .env.local, na mesma pasta do package.json. Use a Project URL e a chave pública do seu projeto:

VITE_SUPABASE_URL=https://SEU-PROJETO.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_SUA_CHAVE

Salve, pressione Control+C no terminal e rode npm run dev novamente. Entre em /login com sua conta.

Use a Publishable key ou a chave pública anon. Nunca use service_role, sb_secret_ nem a senha do banco.

04.Organize a operação.

  1. Cadastre os alimentos reais, confira os preços e envie as fotos.
  2. Use Ajustar estoque para adicionar a produção disponível.
  3. Crie as contas dos voluntários no Supabase e autorize seus e-mails em Nossa equipe.
  4. Clique em Abrir atendimento e informe o fundo de caixa.
  5. Ative Permitir pedidos pelo celular em Configurações.
  6. Se quiser Pix, cadastre a chave e teste os dados do QR no banco antes de divulgar.

05.GitHub e Vercel.

Crie um repositório novo e privado no GitHub. Envie a pasta do projeto. O arquivo .gitignore já exclui as configurações locais e as dependências.

Na Vercel, importe o repositório como Vite, com build npm run build e saída dist. Cadastre as mesmas duas variáveis do Supabase como Config, no ambiente Production.

Se mudar as variáveis após publicar, faça Redeploy. O arquivo LEIA-PRIMEIRO.md tem os comandos completos e os ajustes das URLs de recuperação de senha.

Depois de publicar, gere o QR do cardápio pelo painel online. Caixa, cozinha e clientes precisam de internet.

Uma diferença que importa.

O cliente pode fazer o pedido, mas só a equipe confirma o pagamento. Pix e cartão são conferidos no banco ou na maquininha. A comanda pendente não comprova pagamento.

O sistema registra vendas, troco, devoluções e recibos de controle interno. Ele não transfere dinheiro, não estorna maquininha e não emite nota fiscal.

Pedidos pendentes reservam estoque. Cancele os abandonados para liberar as unidades. Antes de fechar o caixa, entregue ou cancele os pedidos em aberto.
